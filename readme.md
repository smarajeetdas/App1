
# Relay - Next-Gen Test Automation Platform

A comprehensive quality-driven next-generation application offering exceptional user experience in both automated functional testing and non-functional testing.

## Features

### Functional Automation
- End to End Automation Framework
- Selenium and Playwright frameworks support
- API testing with Swagger integration
- Dynamic element handling and custom JS support
- Integration with Vault, CI/CD, and JIRA

### Performance Lab
- Multi-region load testing
- Real-time monitoring
- Performance trend analysis
- Runtime bottleneck identification
- Traffic-based load configuration

### Mobile & Desktop Automation
- Cross-platform testing (Windows & macOS)
- SauceLab & Physical Device execution
- Localization capabilities
- Parallel test execution
- Automated screenshot capture

### Chaos Simulator
- Precision Fault Injection
- Self-Service Chaos GameDays
- Support for Gremlin, AWS FIS, and Chaos Mesh
- End-to-End Infrastructure Coverage
- Multi-cloud environment support

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

The application will be available at `http://localhost:5000`

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Express.js
- Vite
